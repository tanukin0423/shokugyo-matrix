# 🌳 職業マトリクス 16分割
**就活の木 ｜ 就活コンサルタント「キャリ爺」監修**

---

## 📖 このツールについて

「物事への取り組み（成果志向 か プロセス志向 か）」×「人との関わり方（積極的 か 協調的 か）」——2つの軸で**112職種を16のゾーンに分類**した職業探索ツールです。

30問の診断に答えると、自分の座標が自動で計算され、職業マトリクスにジャンプします。気になる職業は厚生労働省の**jobtag**で詳しく調べられます。

---

## 🗂 ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 案内ページ（使い方・ツールへのリンク） |
| `shindan_ver14.html` | 30問の診断ツール（入口） |
| `jobmatrix16v4.html` | 職業マトリクス16分割（出口） |

---

## 🚀 使い方

### Step 1｜診断に答える
`shindan_ver14.html` を開いて30問の質問に答える。自分の座標（4×4の16セルのどこか）が自動で計算されます。

### Step 2｜職業マトリクスへジャンプ
結果画面のボタンをクリックすると `jobmatrix16v4.html` に自動ジャンプ。あなたの座標が★赤枠で強調されます。

### Step 3｜職業群をのぞいてみる
赤枠のセルをクリックすると118職種の一覧が表示されます。職業名にマウスを当てると仕事の説明が表示され、アンダーラインのある職種はjobtag（厚生労働省）へリンクしています。

### Step 4｜隣接ブロックを選んで印刷
点線で囲まれた隣のブロックをクリックして選択できます。「印刷」ボタンで選んだブロックの職業一覧をまとめて印刷できます。

## ✨ 主な特徴

- 🎯 **診断結果から職業マトリクスへ自動ジャンプ**——「自分はここ」が一目でわかる
- 💼 **118職種を収録**——厚生労働省jobtag へのリンクで仕事の実態を詳しく調べられる
- 💬 **全職種に仕事の説明文付き**——マウスを当てるとtooltipで表示
- 🖨️ **選択印刷機能**——気になるブロックを選んでまとめて印刷できる
- 📱 **スマホ・タブレット・PC対応**——どこでも使える

## ⚠️ ご注意

ローカル環境で使用する場合は、**3ファイルを同じフォルダに入れて**ください。

```
📁 任意のフォルダ/
├── index.html
├── shindan_ver14.html
└── jobmatrix16v4.html
```

`shindan_ver14.html` から `jobmatrix16v4.html` へのリンクが連携しています。片方だけでも使えますが、赤枠・点線・印刷機能はセットで使うと動作します。
