# 🌳 職業マトリクス 16分割 ＋ 556職種マトリクス
**就活の木 ｜ 就活コンサルタント「キャリ爺」監修**

---

## 📖 このツールについて

「物事への取り組み（成果志向 か プロセス志向 か）」×「人との関わり方（積極的 か 協調的 か）」——2つの軸で職業を可視化した職業探索ツール群です。

30問の診断に答えると自分の座標が自動で計算され、**16分割マトリクス（大まかな地図）**から**556職種マトリクス（詳細地図）**へと段階的に職種を深掘りできます。気になる職業は厚生労働省の**jobtag**で詳しく調べられます。

---

## 🗂 ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 案内ページ（使い方・ツールへのリンク・QRコード配布カード） |
| `shindan_ver14.html` | 30問の診断ツール（入口） |
| `jobmatrix16v4.html` | 職業マトリクス16分割（112職種・大まかな地図） |
| `jobmatrix_556.html` | 556職種マトリクス（556職種・詳細地図） |

---

## 🚀 使い方

### Step 1｜診断に答える
`shindan_ver14.html` を開いて30問の質問に答える。自分の座標（4×4の16セルのどこか）が自動で計算されます。

### Step 2｜職業マトリクスへジャンプ
結果画面のボタンをクリックすると `jobmatrix16v4.html` に自動ジャンプ。あなたの座標が★赤枠で強調されます。赤枠のセルをクリックすると112職種の一覧が表示されます。

### Step 3｜556職種でさらに深く探す
16分割で「だいたいこのあたり」がわかったら、`jobmatrix_556.html` へ。556職種を同じ2軸で可視化し、カテゴリフィルターで絞り込んで気になる職種を選んで印刷できます。診断結果の座標が自動で引き継がれ、あなたのゾーンが楕円で強調表示されます。

### Step 4｜jobtagで職種研究
印刷した職種名をもとに、jobtag（厚生労働省）で仕事の実態・給与・求められるスキルを詳しく調べましょう。

### Step 5｜インターン・就職活動へ
- **3年生**：気になった職種名でインターンシップを検索して体験してみよう
- **4年生**：職種名をマイナビ・リクナビの検索窓に入れて、職種で絞りながら就活を進めよう

## ✨ 主な特徴

- 🎯 **診断結果から職業マトリクスへ自動ジャンプ**——「自分はここ」が一目でわかる
- 🗺️ **16分割マトリクス（大まかな地図）**——112職種を16ゾーンに分類。まず自分の象限を把握する
- 🌳 **556職種マトリクス（詳細地図）**——556職種を同じ2軸で可視化。カテゴリ別フィルター・楕円ゾーン表示・印刷機能付き
- 🔗 **全556職種にjobtagリンク付き**——厚生労働省の職業情報ページへ直接リンク
- 💬 **全職種に仕事の説明文付き**——マウスを当てるとtooltipで表示
- 🖨️ **選択印刷機能**——気になる職種を選んでカテゴリ別にまとめて印刷できる
- 📱 **スマホ・タブレット・PC対応**——どこでも使える（556職種マトリクスはPC・大きめタブレット推奨）

ローカル環境で使用する場合は、**4ファイルを同じフォルダに入れて**ください。

```

├── index.html
├── shindan_ver14.html
├── jobmatrix16v4.html
└── jobmatrix_556.html
```

それぞれ単独でも使えますが、4つセットで使うと連携機能がすべて動作します。
